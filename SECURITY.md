# Security policy

Password Guruji is a beta candidate for fictional-data testing. It has not received an independent security audit and is not approved for storing real secrets.

## Reporting a suspected vulnerability

Do not publish passwords, vaults, keys, recovery codes, personal information, or exploit details in public issues. Use the repository's **Security → Report a vulnerability** private reporting option if it is available. If it is unavailable, contact the maintainer through https://dparab.me or https://www.linkedin.com/in/devdutt-parab to request a private channel before sending details. Private reporting availability has not been verified; there is no promised response time.

Include the source commit, OS and Java/runtime version, affected feature, impact, and minimal reproduction using fictional data. Describe expected and observed behavior. Keep logs and screenshots free of secrets. Do not test against another person's files or accounts.

Supported fixes currently target the development candidate on feature/cross-platform-beta-readiness. There is no supported production release. See documentation/SECURITY-REVIEW.md for findings and limitations.
