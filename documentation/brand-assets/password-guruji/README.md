# Password Guruji product branding

Original PNG artwork supplied by the project owner in Password-Guruji.zip, integrated on 20 November 2026. Originals are retained unchanged, including the concept and branding reference.

- Password-Guruji_app_icon.png: source product icon.
- Password-Guruji_logo_banner.png: repository banner.
- Password-Guruji_branding_reference.png: reference artwork.
- Concepts/password_guruji_security_logo.png: original concept.
- password-guruji.ico: Windows launcher icon with seven sizes from 16 to 256 pixels.

Regenerate the ICO and bundled PNG sizes from the repository root using `java tools/BuildProductIcons.java .`. The supplied icon is centered on a transparent square and scaled without cropping or redrawing. The largest derived size is upscaled from the supplied original.

The app uses these product icons in its window and headings, and the package uses the ICO for the Windows executable. Existing Mirakinetix artwork remains in the parent directory as historical brand material. Reference artwork does not add links to the application; the existing LinkedIn and personal website footer links remain.
